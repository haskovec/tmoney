⏺ Done! Updated NewID() to use UUID v7 instead of v4.

  Benefits of UUID v7:
  - Time-ordered (48-bit Unix timestamp in milliseconds)
  - Sequential IDs cluster together in B-tree indexes
  - Better insert performance and cache locality
  - Still globally unique with random suffix bits

  The implementation falls back to v4 if v7 generation fails (unlikely edge case with clock issues).
