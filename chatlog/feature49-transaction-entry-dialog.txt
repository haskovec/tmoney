│ Types:                                                                                                                                   │
│ - transactionDialogData - holds loaded payees, categories, and a payeeMap (lowercase name -> payee) for auto-fill lookup                 │
│ - transactionDialogDataMsg - async message when dialog data is loaded                                                                    │
│ - transactionDialogSavedMsg - async message when transaction is saved                                                                    │
│                                                                                                                                          │
│ Pure helper functions:                                                                                                                   │
│ - parseDateInput(input string) (models.Date, error) - parse "MM/DD/YYYY" format                                                          │
│ - parseAmountInput(input string) (models.Money, error) - strip "$", handle negatives, parse via models.NewMoney()                        │
│ - buildCategoryOptions(categories []*models.Category) ([]string, []models.ID) - build parallel display names / IDs slices. First entry   │
│ "(None)" with nil ID. Subcategories formatted as "Parent > Child". Exclude system categories. Sort alphabetically.                       │
│ - buildTransactionDialog(data *transactionDialogData, categoryOptions []string) *Dialog - creates Dialog with 6 fields:                  │
│   - Date (FieldText, default today MM/DD/YYYY)                                                                                           │
│   - Payee (FieldText, empty, placeholder "Payee name")                                                                                   │
│   - Category (FieldSelect, options from categories, default "(None)")                                                                    │
│   - Amount (FieldText, empty, placeholder "-50.00")                                                                                      │
│   - Memo (FieldText, empty, placeholder "Optional memo")                                                                                 │
│   - Status (FieldRadio, ["Pending", "Cleared"], default 0)                                                                               │
│                                                                                                                                          │
│ App methods:                                                                                                                             │
│ - loadTransactionDialogData() tea.Cmd - async load payees + categories                                                                   │
│ - closeTransactionDialog() - nil out dialog state                                                                                        │
│ - checkPayeeAutoFill() - if payee field matches known payee with default category, update category dropdown                              │
│ - handleTransactionDialogKey(msg) (tea.Model, tea.Cmd) - delegate to dialog.HandleKey(), handle Submit/Cancel                            │
│ - submitTransactionDialog() (tea.Model, tea.Cmd) - parse fields, validate, close dialog, return async cmd that creates transaction       │
│                                                                                                                                          │
│ 2. Modify internal/tui/app.go                                                                                                            │
│                                                                                                                                          │
│ - Add fields to App struct: txnDialog *Dialog, txnDialogData *transactionDialogData, txnDialogCategoryIDs []models.ID                    │

│ - handleRegisterKeys(): Add case key.Matches(msg, a.keys.New) when table focused → loadTransactionDialogData()                           │
│ - Update(): Handle transactionDialogDataMsg (build dialog, set visible) and transactionDialogSavedMsg (reload register + sidebar)        │
│ - renderLayout(): After menu overlay, overlay txnDialog.Render() via OverlayCenter() when visible                                        │

│ Key Design Decisions                                                                                                                     │
│                                                                                                                                          │
│ 1. Date format MM/DD/YYYY - familiar US format; converts to internal models.Date at the boundary                                         │
│ 2. "(None)" as first category option - category is optional; index 0 maps to nil ID                                                      │
│ 3. Auto-fill on exact payee match only - checks on every keystroke but only fills when full name matches (case-insensitive)              │
│ 4. Close dialog before async save - responsive UI; errors surface through standard errMsg flow                                           │
│ 5. Reload sidebar after save - account balances change when transactions are added                                                       │
