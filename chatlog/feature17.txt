     Plan: Add --create Flag for New Database Creation

     Summary

     Add a --create CLI flag that allows first-time users to create a new TMoney database file with all migrations applied.

     Current State

     - db.Create(path) exists in internal/db/connection.go and handles:
       - Creating the database file
       - Adding .tdb extension if missing
       - Creating parent directories
       - Running migrations to set up schema
       - Initializing metadata table
     - The CLI (cmd/tmoney/main.go) doesn't expose this functionality
     - Users cannot create a new database from the command line

     Implementation

     1. Add --create Flag to CLI Options

     File: cmd/tmoney/main.go

     Add to cliOptions struct:
     createDB string  // path for new database to create

     Add to parseArgs():
     case "--create":
         if i+1 >= len(args) {
             return nil, nil, fmt.Errorf("--create requires a path argument")
         }
         i++
         opts.createDB = args[i]

     Also handle --create=path format.

     2. Add runCreateDB Function

     File: cmd/tmoney/main.go

     func runCreateDB(opts *cliOptions, w io.Writer) error {
         database, err := db.Create(opts.createDB)
         if err != nil {
             return fmt.Errorf("failed to create database: %w", err)
         }
         defer database.Close()

         fmt.Fprintf(w, "Created database: %s\n", database.Path())
         return nil
     }

     3. Add Handler in run() Function

     Add before the --list-accounts check:
     if opts.createDB != "" {
         return runCreateDB(opts, stdout)
     }

     4. Update Help Text

     Add to printHelp():
     Database Commands:
       --create <path>    Create a new database file

     5. Write Tests

     File: cmd/tmoney/main_test.go

     Create tests for:
     - --create /path/to/new.tdb creates database successfully
     - --create existing.tdb returns appropriate error
     - --create without path returns error
     - --create=path format works
     - Created database can be opened with --list-accounts

     Files to Modify

     1. cmd/tmoney/main.go - Add flag, handler, help text
     2. cmd/tmoney/main_test.go - Add tests (create new file)

     Verification

     1. Build: go build ./cmd/tmoney
     2. Run tests: go test ./cmd/tmoney/...
     3. Manual test:
     ./tmoney --create /tmp/test.tdb
     ./tmoney --file /tmp/test.tdb --list-accounts
     4. Verify error handling:
     ./tmoney --create  # should error: requires path
     ./tmoney --create /tmp/test.tdb  # should error: already exists
